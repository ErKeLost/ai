# 成本：提示词到底多大 🍰

<div class="gu-grid g4">
  <div class="gu-kpi"><b>1.3k</b><span>32 个组件 · 一句话描述</span></div>
  <div class="gu-kpi"><b>5.2k</b><span>32 个组件 · 描述写详细</span></div>
  <div class="gu-kpi"><b>6.5k</b><span>67 个组件 · 完整签名</span></div>
  <div class="gu-kpi"><b>9.0k</b><span>82 个组件 · 详描述 + 6 例子</span></div>
</div>

<div class="gu-small" style="margin:0.8rem 0 0.4rem">单位：tokens（每次请求都要重发这一整块）</div>

| 结论 | 数据 |
| --- | --- |
| **组件个数不是成本，描述长度才是** | 同样 32 个组件：描述一句话 → 1,333 tokens；写成四句话 → **5,231 tokens（涨 4 倍）** |
| **真正的「价格炸弹」是内联展开** | 图表组件 `data.chart` 一个参数把 40 种图表的模板全展开 = **8,256 字符，占整块 32%** |
| **容器不要列全部子组件** | 只给容器列 32 个子组件 → +333 字符；若 10 个容器各列一遍 → 成倍膨胀 |
| **给一个例子最划算** | 一个具体示例往往顶十句规则；但控制在 2~3 个 |

<div class="gu-quote" style="margin-top:0.9rem">
"把 shadcn 的 63 个组件全都要"完全可行 —— 一句话描述总共约 1.3k tokens。<strong>别把描述写成文档就行。</strong>
</div>
