# 插件扩展（Plugin Extensions）

> 完整的文档索引请参阅 [llms.txt](/llms.txt)。在页面 URL 末尾加上 `.md` 即可获取对应文档页面的 Markdown 版本。

OpenAI MCP Extensions 让开发者能够把自己的插件接入 ChatGPT 用户体验的各个关键界面（surface），包括侧边栏（sidebar）、composer（消息输入框）和文件查看器。

网页端的插件扩展即将面向 ChatGPT Free 和 Go 用户推出。
  现有插件功能不受影响。Composer mentions（输入框提及）目前仅
  在 ChatGPT 桌面应用中可用。

| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |

| | [会话面板](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#thread-entrypoint)                               | 让用户在会话旁边打开你的应用，让工作和聊天同屏进行。                                                         |
| | [插件设置](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#structured-settings)                             | 让用户直接在 ChatGPT 中配置你插件的专属设置。                                                               |
| | [文件查看器与编辑器](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#file-extension-entrypoint)             | 在你自己的界面中打开受支持的文件，读取、实时更新和保存更改一体化处理。                                       |

### 侧边栏应用（Sidebar apps）

在全局侧边栏中添加一个条目，点击后可全屏启动你的 MCP App。



[从侧边栏打开 Bits & Bolts CAD 零件库](https://developers.openai.com/videos/plugins/extensions/sidebar-entrypoint.mp4)



注册 MCP App 工具时，请将这段元数据作为 `_meta` 传入。把
`ui://parts/library` 替换为你已注册的 UI 资源 URI：

```ts


const toolMetadata = {
  ui: { resourceUri: "ui://parts/library" },
  "openai/ui": {
    entrypoints: [{ type: "global" }],
  } satisfies OpenAIUiToolMetadata,
};
```

使用 `{ type: "thread" }` 可以在会话的侧边面板（side panel）中添加一个入口点（entrypoint）。
完整的注册示例请参阅[入口点指南](https://github.com/openai/mcp-extensions/blob/main/typescript/README.md#ui-entrypoints)。

### 文件查看器与编辑器

当用户打开受支持扩展名的文件时，你的 MCP App 将在线程侧边栏（thread side panel）中打开。



[在 Bits & Bolts 文件查看器中打开 CAD 文件](https://developers.openai.com/videos/plugins/extensions/file-viewer.mp4)



在工具的 `_meta` 中使用 file 类型的 entrypoint，并声明你的查看器支持的扩展名：

```ts


const toolMetadata = {
  ui: { resourceUri: "ui://parts/viewer" },
  "openai/ui": {
    entrypoints: [{ type: "file", extensions: ["stl"] }],
  } satisfies OpenAIUiToolMetadata,
};
```

将 `ui://parts/viewer` 替换为你已注册的 UI resource。应用会收到所打开文件对应的 resource URI。按照 [file handler 指南](https://github.com/openai/mcp-extensions/blob/main/typescript/README.md#file-extension-handlers)接收该输入，并使用 app SDK 读取该资源。

### 扩展表单

使用 ChatGPT 原生的更丰富组件来扩展标准 MCP 表单。



[在 Bits & Bolts 表单中选择图片](https://developers.openai.com/videos/plugins/extensions/image-picker.mp4)



```ts


function partSelectionSchema(parts: OpenAIFormOption[]): OpenAIForm {
  return {
    type: "object",
    properties: {
      part: {
        type: "string",
        title: "Part",
        oneOf: parts,
      },
    },
    required: ["part"],
  };
}
```

在表单请求中将此 schema 作为 `requestedSchema` 传入。每个选项使用 `const` 和 `title`，并可选地附带 `x-openai-thumbnail` 图标。
经 OpenAI 注册的 MCP 服务器需要使用 [multi-round-trip requests（MRTR，多轮往返请求）](https://modelcontextprotocol.io/specification/2026-07-28/basic/patterns/mrtr)。
