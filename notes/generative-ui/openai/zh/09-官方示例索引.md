## 概述

Pizzaz 演示捆绑了多个 UI 组件，让你能够端到端地看到工具的完整能力范围。接下来的几节将逐一介绍 MCP 服务器，以及为这些工具提供支撑的组件实现。
你可以在我们的 [GitHub 示例仓库](https://github.com/openai/openai-apps-sdk-examples)中找到 Pizzaz 及其他示例。

在组装自己插件的 MCP 服务器和可选 UI 时，可以将这些示例作为蓝图。
